# Mapas históricos integrados à linha do tempo

- Os mapas aparecem na própria linha do tempo; não existe botão/painel separado de camada histórica.
- A galeria inicial cobre mapas-múndi e cartografia histórica de várias épocas.
- O app consulta a API pública do Wikimedia Commons para localizar imagens/miniaturas e usa links de fallback para os arquivos conhecidos.
- Mapas sem georreferenciamento são exibidos como imagens documentais, com localização aproximada no mapa atual. A posição é ilustrativa, não uma georreferência do documento.
- A licença e a atribuição devem ser conferidas no registro individual do arquivo antes de qualquer redistribuição. O link da fonte é mostrado no cartão.
- As imagens são carregadas pela internet em tempo de execução; não foram empacotadas como arquivos binários locais nesta versão, pois o ambiente de edição não teve acesso de rede para baixar e validar os originais.
